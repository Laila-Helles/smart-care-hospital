# Smart Care Hospital System

A Java OOP console-based hospital management system developed as a university project for ITMB 1107.

## Project Overview

Smart Care Hospital is a simple hospital management system that manages doctors, nurses, patients, and medical appointments using Java and Object-Oriented Programming.

## Main Features

- Doctor management
- Patient registration
- Appointment booking
- Appointment display
- Automatic Person IDs
- File I/O
- Exception handling
- Console-based menu

## OOP Concepts

- Encapsulation
- Inheritance
- Constructor Overloading
- `this()` and `super()`
- Method Overriding
- Polymorphism
- HAS-A relationships
- ArrayList
- File I/O
- Custom Exceptions

## Main Classes

- `Person`
- `Employee`
- `Doctor`
- `Nurse`
- `Patient`
- `Appointment`
- `DoctorUnavailableException`

## Technologies

- Java
